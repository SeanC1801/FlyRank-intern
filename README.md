# FlyRank API

This repository contains the backend API for FlyRank. It is built using FastAPI and uses an SQLite database for data persistence. 

## Progress
- Set up a FastAPI application (`main.py`).
- Integrated an SQLite database (`tasks.db`) to store tasks.
- Implemented CRUD (Create, Read, Update, Delete) operations for tasks.
- Configured Uvicorn to run the application on host `0.0.0.0`.
